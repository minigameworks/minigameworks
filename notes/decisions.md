# 기술적 의사결정

## 2026-07-30: Phaser 3와 Matter Physics 통합 사용

### 배경

2D 물리 기반 클라이밍 게임을 정적 웹 환경에서 실행해야 한다.

### 결정

Phaser 3를 게임 프레임워크로 사용하고, 물리 엔진은 Phaser가 제공하는 Matter Physics 통합 기능을 사용한다.

### 이유

Phaser 3는 브라우저 기반 2D 게임 제작에 적합하고, Matter Physics 통합을 통해 별도 Matter.js 의존성 없이 물리 바디와 충돌을 다룰 수 있다.

### 영향

게임 실행과 UI는 Phaser Scene 중심으로 구성한다. Matter.js를 별도 패키지로 설치하지 않는다.

## 2026-07-30: 개발 문서는 notes 디렉터리에 작성

### 배경

프로젝트 문서 위치를 일관되게 유지해야 한다.

### 결정

내부 개발 문서는 `docs/`가 아니라 `notes/` 아래에 작성한다.

### 이유

작업 명세에서 지정한 문서 구조와 에이전트 작업 절차를 일관되게 따르기 위해서다.

### 영향

게임 콘셉트, 아키텍처, 개발 방법, 의사결정 문서는 모두 `notes/`에서 관리한다.
