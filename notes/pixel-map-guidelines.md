# 픽셀 맵 제작 기준

## 목표

초기 맵은 Tiled에서 8px 타일 그리드로 지형을 이어 붙여 관리한다. 코드에서 자유 좌표 오브젝트를 많이 배치하지 않고, 반복 가능한 타일 단위로 땅 덩어리와 절벽 구조를 만든다.

## 기본 픽셀 단위

- 기본 타일 크기: `8px x 8px`
- 보조 정렬 단위: `4px`
- 큰 구조물 기준 단위: `16px`
- 게임 캔버스: `960px x 540px`
- 초기 수직 맵 너비: `960px`
- 현재 초기 수직 맵 높이: `1620px`

좌표와 크기는 기본적으로 8px 배수에 맞춘다. 달팽이 접촉을 부드럽게 조정해야 하는 경우에만 4px 단위 예외를 허용한다.

## Tiled 레이어 기준

`public/assets/tilemaps/initial-vertical.tmj`는 다음 레이어를 사용한다.

- `metadata`: 레벨 크기, 벽 두께, 레벨 이름 같은 메타 정보다.
- `markers`: 시작점, 도착점, 체크포인트 같은 기준점이다.
- `walls`: 좌우 벽 디자인 타일 레이어다.
- `ground`: 바닥 디자인 타일 레이어다.
- `terrain`: 도트 디자인을 덮는 타일 레이어다.
- `surfaces`: 실제 지형 구현체다. polygon과 rectangle 내부는 채워진 충돌 지형이다.

원칙은 `surfaces` polygon으로 실제 지형을 먼저 만들고, `terrain` 타일은 그 위에 도트
디자인을 덮는 용도로 사용한다. 계단형 픽셀 타일을 런타임에서 충돌 지형이나 경사 접면으로
추측하지 않는다.

## 개발용 타일 구분

현재 개발용 타일셋은 `public/assets/tilemaps/dev-terrain.tsx`와 `public/assets/images/dev-terrain-tiles.svg`다.

| GID | 용도    | 사용 레이어 |
| --: | ------- | ----------- |
| `1` | 일반 땅 | `terrain`   |
| `2` | 벽      | `walls`     |
| `3` | 바닥    | `ground`    |

추후 픽셀 디자인을 적용할 때도 이 구분은 유지하고, 각 GID에 연결된 실제 타일 이미지만 교체한다.

## 기본 오브젝트 픽셀 값

| 항목           |   권장 값 | 비고                                          |
| -------------- | --------: | --------------------------------------------- |
| 기본 지형 타일 |   `8 x 8` | Tiled `terrain` 레이어에서 디자인으로 칠한다. |
| 벽 두께        |      `24` | 8px 타일 3칸이다.                             |
| 바닥 두께      |      `24` | 8px 타일 3칸이다.                             |
| 작은 발판 높이 |      `16` | 8px 타일 2칸이다.                             |
| 일반 발판 높이 |      `24` | 8px 타일 3칸이다.                             |
| 작은 발판 길이 |   `64-96` | 8px 타일 8-12칸이다.                          |
| 일반 발판 길이 | `128-192` | 8px 타일 16-24칸이다.                         |
| 긴 발판 길이   | `240-320` | 8px 타일 30-40칸이다.                         |
| 기본 통로 폭   | `96` 이상 | 달팽이 몸 크기와 방향 표시 여유를 포함한다.   |
| 안전 발판 여유 | `64` 이상 | 착지/접면 전환 확인용 최소 여유다.            |

## 접면 제어선 기준

지형은 `surfaces` 오브젝트 레이어의 Polygon Object 또는 Rectangle Object로 그린다. 내부는
전부 채워진 충돌 지형이고, 벽/바닥과 겹친 edge를 제외한 노출 edge를 달팽이가 타는 접면으로
사용한다.

벽이나 바닥에 붙는 지형은 Tiled에서 벽/바닥 안쪽으로 8-12px 정도 넉넉하게 겹쳐 그린다.
런타임은 필드 경계와 겹친 edge를 접면 후보에서 제외하고, 남은 사선이나 노출된 면만
`SurfaceEdge`로 변환한다.

- 완만한 경사: `15도`
- 기본 경사: `30도`
- 반대 방향 경사: `-15도`, `-30도`

polygon과 rectangle은 각 edge가 polygon 중심의 바깥쪽을 향하도록 법선을 계산한다.

## 달팽이 픽셀 정의

현재 달팽이는 최종 도트 스프라이트가 아니라 물리 기준 마커로 표시한다.

| 항목                     |   현재 값 | 비고                                 |
| ------------------------ | --------: | ------------------------------------ |
| 일반 상태 전체 기준 크기 |      `44` | Matter 원형 body 기준이다.           |
| 일반 상태 몸통 반지름    |      `13` | 화면에는 원 2개로 표시한다.          |
| 일반 상태 몸통 간격      |      `20` | 앞/뒤 몸통 중심 간격이다.            |
| 일반 상태 연결부         | `26 x 16` | 현재 시각 표현이다.                  |
| 껍질 상태 반지름         |      `22` | 껍질 상태 Matter 원형 body 기준이다. |
| 접면 normal 깊이         |      `13` | 일반 상태 접면 스냅 깊이와 맞물린다. |

도트 캐릭터 에셋을 만들 때는 현재 물리 기준에 맞춰 `44px` 안에 들어오는 기본 자세를 우선한다. 이후 애니메이션 단계에서 실제 보이는 스프라이트는 물리 body보다 약간 커질 수 있지만, 접면 기준점은 현재 body 중심과 맞춰야 한다.

## 편집 규칙

- 좌우 벽은 `walls` 레이어에서 벽 타일로 이어 붙인다.
- 바닥은 `ground` 레이어에서 바닥 타일로 이어 붙인다.
- 실제 충돌 지형은 `surfaces` 레이어에서 polygon으로 그린다.
- 도트 디자인은 `terrain` 레이어에서 땅 타일로 이어 붙여 surface 위에 덮는다.
- 지형 덩어리는 비어 있는 틈이 없게 칠한다.
- 발판 하나를 만들 때도 가능하면 8px 타일 여러 개로 만든다.
- `surfaces` polygon은 실제 충돌 지형이다. 내부는 전부 채워져 있고 달팽이가 들어갈 수 없다.
- 시작점과 도착점은 `markers` 레이어에서 관리한다.
- 미끄럼, 바람, 범퍼 같은 기믹은 별도 오브젝트 레이어로 분리할 예정이다.

## 현재 제한

현재 런타임은 `terrain` 타일을 도트 지형 표시용으로만 사용한다. `terrain`, `walls`,
`ground` 타일은 달팽이 접면 후보나 개별 충돌 구현체로 인식하지 않는다. 접면과 지형 충돌
구현체는 `surfaces` 레이어에서 만든다. polygon과 rectangle은 접면과 채워진 충돌체를 함께
만든다. 단, 기본 좌우 벽과 바닥은 기존 `field` 경계 충돌체와 경계 접면으로 유지한다.

`walls`와 `ground`는 현재 필드 경계와 중복 충돌을 만들지 않도록 디자인 레이어로만 둔다. 실제 좌우 벽과 바닥의 기본 충돌은 아직 `field` 경계에서 생성한다.

아직 도트 타일 레이어를 최종 비주얼로 렌더링하지는 않는다. 현재는 Tiled의 타일 레이어를 지형 데이터로 사용하고, 화면 표시는 Phaser Graphics로 유지한다.
