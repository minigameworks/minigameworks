# 아키텍처

## 프로젝트 구조

- `src/config`: Phaser와 게임 전역 설정
- `src/scenes`: Phaser Scene
- `src/entities`: 게임 오브젝트와 엔티티
- `src/states`: 상태 머신과 상태 정의
- `src/systems`: 입력, 물리 보조, 기록 같은 시스템 로직
- `src/ui`: Phaser 내부 HUD와 UI
- `src/utils`: 테스트 가능한 순수 유틸리티
- `public/assets`: 정적 에셋
- `tests`: Vitest 테스트

## Scene 구조

현재 Scene 구조는 다음과 같다.

- `BootScene`: 초기 진입용 Scene이다. 현재는 바로 `GameScene`으로 전환한다.
- `GameScene`: 실제 플레이 공간과 플레이어를 생성하고 업데이트한다.

수직 레벨 확장은 `BootScene`이 아니라 `GameScene`과 플레이필드 시스템을 기준으로 진행한다. 후속 작업에서 시작 화면, 결과 Scene 등을 추가로 분리한다.

## 플레이어와 플레이필드

- `src/entities/SnailPlayer.ts`: 임시 달팽이 플레이어, 일반 상태와 껍질 상태 전환, 이동, 접면 부착, 껍질 점프, 임시 시각 표시를 담당한다.
- `src/systems/SnailInputController.ts`: 방향 입력, 점프 입력, 상태 전환 입력을 읽어 플레이어가 사용할 수 있는 단순 값으로 변환한다.
- `src/systems/TemporaryPlayfield.ts`: 임시 플레이 공간, 바닥과 좌우 벽, 임시 구조물 생성, 시작 위치, 접면 후보와 지지면 판정을 담당한다.

현재 플레이어와 플레이필드는 MVP 조작 검증을 위한 임시 구현이다. 최종 그래픽, 최종 물리 수치, 최종 레벨 구조는 아직 확정하지 않는다.

### 임시 플레이필드 구성

현재 필드는 `TEMPORARY_PLAYFIELD`와 `TEMPORARY_PLATFORMS` 설정을 기준으로 코드에서 직접 생성한다. 이 구성은 일반 상태의 접면 부착, 벽타기, 껍질 상태의 경사면 이동, 점프, 카메라 확장 가능성을 확인하기 위한 임시 형태다.

현재 임시 필드 요소는 다음 기준으로 구성한다.

- 전체 화면을 사용하는 수직 플레이 공간
- 좌우 벽과 하단 바닥
- 왼쪽 벽에서 접근할 수 있는 경사 구조물
- 오른쪽 벽에 붙어 있는 구조물
- 점프와 접면 전환을 확인하기 위한 추가 구조물

후속 레벨 작업에서는 이 임시 필드 요소를 그대로 확장하지 않는다. 필드 요소는 최소한 다음 단위로 분리한다.

- 경계 요소: 바닥, 좌우 벽, 천장 또는 낙하 제한선
- 정적 발판: 수평 발판, 경사 발판, 벽 부착 발판
- 기믹 요소: 스프링, 범퍼, 가속 발판, 위험 지형
- 시작점과 목표 지점
- 체크포인트와 카메라 구간

최종 레벨 구조는 Tiled Map Editor 또는 별도 레벨 데이터 로더를 기준으로 관리한다. `TemporaryPlayfield`는 조작 프로토타입 검증용 시스템으로 유지하고, 실제 레벨 제작 단계에서는 `LevelLoader`, `LevelGeometry`, `SurfaceResolver` 같은 역할로 분리한다.

### 접면 판정

일반 상태는 구조물의 위, 아래, 옆면에 붙어 접면을 따라 이동할 수 있다. 현재 접면 판정은 `AttachmentSurface`와 `AttachmentProbe`를 사용한다.

- `AttachmentSurface`: 접면의 법선, 접선, 스냅 위치를 표현한다.
- `AttachmentProbe`: 달팽이의 접면 방향 길이와 접면 수직 깊이를 분리해 판정한다.

껍질 상태는 벽에 붙지 않고, 바닥이나 경사처럼 달팽이를 받치는 지지면만 접지와 경사 가속에 사용한다.

## 상태 관리

현재 일반 상태와 껍질 상태는 `SnailPlayer` 내부의 임시 상태값으로 관리한다. 후속 작업에서는 `src/states` 아래의 순수 상태 머신으로 먼저 정의한다. Phaser Scene은 상태 머신 결과를 읽어 물리 바디와 애니메이션에 반영하는 방향을 우선한다.

## 물리 엔진

Matter Physics는 Phaser 통합 기능을 사용한다. Matter.js를 별도 패키지로 설치하지 않는다.

현재 설정의 중력과 디버그 표시는 실행 확인용 임시값이며 최종 게임 규칙이 아니다.
