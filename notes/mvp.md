# MVP 진행 계획

## 목표

7~8일 안에 완성할 MVP는 짧지만 완주 가능하고, 달팽이의 일반 상태와 껍질 상태 전환 재미가 명확하게 보이는 수직 클라이밍 게임이다.

핵심 기준은 기능 수가 아니라 한 판의 완성도다. 플레이어가 시작하고, 조작하고, 위험한 선택을 하고, 정상에 도착해 기록을 확인한 뒤 다시 도전할 수 있어야 한다.

## 진행 원칙

- 모든 MVP 작업은 GitHub Issue 기반으로 진행한다.
- 관련 Issue가 없으면 먼저 Issue를 만든 뒤 브랜치를 생성한다.
- 브랜치명에는 Issue 번호를 포함한다.
- 하루 단위로 병합 가능한 작은 범위로 작업한다.
- 6일차 이후에는 큰 구조 변경보다 밸런싱, 버그 수정, 완성도 개선에 집중한다.
- 랭킹 서버, 긴 맵, 복잡한 애니메이션, 다수 캐릭터, 과도한 기믹은 MVP 범위에서 제외한다.

## 2인 진행 방식

역할은 고정하지 않는다. 매일 작업 시작 시 그날의 목표를 기준으로 나눈다.

- 한 명은 플레이 가능한 기능 연결을 맡는다.
- 한 명은 레벨, 피드백, 문서, QA를 병렬로 진행한다.
- 하루 끝에는 항상 실행 가능한 상태로 합친다.
- 큰 기능보다 작은 Issue 단위 완료를 우선한다.

## MVP 제외 범위

- 온라인 랭킹 서버
- 긴 최종 맵
- 복잡한 캐릭터 애니메이션
- 다양한 플레이어블 캐릭터
- 많은 종류의 기믹
- 정교한 컷신
- 대규모 에셋 제작
