# 기믹 케이스 관리

## 목적

기믹 케이스는 특정 구조물 패턴이나 물리 동작을 메인 수직 맵까지 이동하지 않고 바로 검증하기 위한 작은 플레이어블 레벨이다.

신규 기믹은 먼저 이 문서에 등록하고, `src/systems/TemporaryLevelDefinitions.ts`에 케이스 레벨을 추가한 뒤 `/?case=케이스키`로 실행해 검증한다. 검증이 끝난 케이스만 메인 수직 맵 상단 구간에 붙인다.

## 관리 규칙

- 케이스 키는 영문 소문자와 하이픈을 사용한다.
- 케이스는 하나의 기믹 또는 하나의 구조물 패턴 검증에 집중한다.
- 검증 전에는 메인 수직 맵에 바로 붙이지 않는다.
- 검증 완료 후 메인 맵에 붙이면 `메인 맵 반영` 상태를 갱신한다.
- 실패하거나 보류한 케이스는 삭제하지 않고 이유를 남긴다.

## 상태 값

- `계획`: 아직 코드에 추가하지 않은 케이스
- `구현`: 케이스 씬에서 실행 가능한 상태
- `검증 중`: 실제 플레이 감각과 버그를 확인하는 상태
- `검증 완료`: 메인 맵에 붙일 수 있는 상태
- `반영 완료`: 메인 수직 맵에 붙인 상태
- `보류`: 현재 방향으로 사용하지 않기로 한 상태

## `slope-transfer`

### 목표

경사 발판, 벽 부착 발판, 반대 방향 경사 발판을 짧은 구간에서 배치해 다음 동작을 확인한다.

- 일반 상태의 접면 부착과 접면 전환
- 껍질 상태의 경사면 이동
- 낮은 점프 후 구조물에 다시 붙는 흐름

### 실행

```text
http://localhost:5173/?case=slope-transfer
```

### 체크리스트

- [x] 케이스 레벨 정의가 있다.
- [x] URL 쿼리로 케이스 씬을 바로 실행할 수 있다.
- [ ] 일반 상태에서 경사면을 자연스럽게 이동할 수 있다.
- [ ] 껍질 상태에서 경사 방향 이동을 확인했다.
- [ ] 점프 후 다음 구조물에 붙는 흐름을 확인했다.
- [ ] 메인 수직 맵 상단 구간에 반영했다.

### 메모

현재는 세로 맵 확장 구조와 케이스 씬 실행 흐름 검증용이다. 최종 기믹 밸런스와 구조물 배치는 아직 확정하지 않는다.
